# Faultline satellite demo assets

Downloaded September 8, 2026. These are real source images for dataset thumbnails and processing previews. No generated imagery. Optimized variants preserve source color and framing, with JPEG compression and downsizing only. Original downloads remain alongside them.

## Namib dunes
- File: `namib-dunes.jpg` (1100 × 1100, ~261 KB)
- Original: `namib-dunes-original.jpg` (4500 × 4500)
- Source page: https://science.nasa.gov/earth/earth-observatory/namib-naukluft-national-park-namibia-2804/
- Exact downloaded image: https://assets.science.nasa.gov/content/dam/science/esd/eo/images/imagerecords/2000/2804/landsat_art_namib_lrg.jpg
- Credit: USGS EROS Data Center Satellite Systems Branch / NASA Earth Observatory.
- Landsat 7 ETM+, acquired August 12, 2000. False color with near infrared, green and blue; source sharpened using panchromatic band.
- Visual: orange dune ridges with pale blue dry channel; good detailed processing preview. Square source suitable for `object-fit: cover` in a wide card, or full square view.

## Reuse
USGS explicitly states Landsat data are public domain, permission is not required, and asks for source acknowledgment: https://www.usgs.gov/faqs/are-landsat-data-cloud-still-considered-be-within-public-domain

NASA factual educational/informational imagery use is generally permitted with source acknowledgment and without implying NASA endorsement. These source pages identify no third-party copyright claim. The selected images contain no people, NASA logos or marks. NASA usage reference: https://www.nasa.gov/nasa-brand-center/images-and-media/

Suggested compact in-app source credit: “Source imagery: NASA Earth Observatory / USGS.” More specific per-image credits above.
